# UI comparison bars

- [KColorChooser](https://apps.kde.org/kcolorchooser): native Breeze application typography, controls, spacing and window treatment.
- [KDE Plasma Color Picker](https://github.com/KDE/kdeplasma-addons/tree/master/applets/colorpicker): native tray integration, compact swatch history, square cells, centered code labels, theme integration, and action tooltips. Added by user during refinement, with supplied dark-theme screenshots.

User screenshots are design references, not same-scale runtime evidence. Current master QML explicitly uses three columns, square cell pitch, a theme-colored label strip with centered text, and Plasma highlight. Local native applet comparison uses Debian Plasma 6.3.5, not current master; record this distinction in verdicts. Both bars remain active; a history-task win does not establish full color chooser feature parity.
